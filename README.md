**Демо:** https://seitek2002.github.io/green-api-telegram-chat/

**Видео-презентация:** https://youtu.be/5K5gJmZx9Xo

## Запуск проекта

Требуется Node.js 20+.

```bash
git clone https://github.com/Seitek2002/green-api-telegram-chat.git
cd green-api-telegram-chat
npm install
npm run dev
```

Приложение откроется на http://localhost:5173. Для входа используйте `idInstance` и `apiTokenInstance` из [личного кабинета GREEN-API](https://console.green-api.com).
